วิธีใช้ระบบจัดเก็บราคาสินค้าแบบ Local

1) เปิดไฟล์ local_price_excel_system.html ด้วย Chrome / Edge / Firefox
2) เพิ่มสินค้าในแท็บ “สินค้า” และเพิ่มห้างในแท็บ “ห้าง/ร้าน”
   ระบบมีตัวอย่างห้าง Top, BigC, Lotus และสินค้าตัวอย่างให้เริ่มใช้งาน
3) ไปที่แท็บ “บันทึกราคา”
   - เลือกวันที่และห้าง
   - ติ๊กสินค้าเป็นรายการ
   - ใส่ราคา
   - เลือก/ไม่เลือกช่อง “คำนวณ”
   - กด “บันทึกราคา”
4) ระบบจะเก็บข้อมูลในเครื่องผ่าน Local Storage
5) ถ้าเปิด “ดาวน์โหลด Excel หลังบันทึกทุกครั้ง” ระบบจะดาวน์โหลดไฟล์ .xls ทุกครั้งที่บันทึก/แก้ไข/ลบ
6) ใช้แท็บ “ประวัติ/คำนวณ” เพื่อดู Rel, ราคาเดิม, ราคาเปลี่ยน และ Export ตามตัวกรอง
7) ใช้แท็บ “สำรองข้อมูล” เพื่อ Export JSON สำหรับนำกลับเข้าในอนาคต

หมายเหตุ:
- ไฟล์ Excel ที่ส่งออกเป็น .xls แบบ Excel XML เปิดได้ใน Microsoft Excel
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้ หากล้าง cache/local storage ข้อมูลจะหาย
- ควรสำรองเป็น Excel หรือ JSON เป็นระยะ
